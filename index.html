Quem Codifica

Busco uma oportunidade de estágio em Front-end ou áreas correlatas de desenvolvimento, onde eu possa aprender, experimentar e resolver problemas no mundo tech.

FarmCode

Sistema de gerenciamento de sêmen bovino congelado, desenvolvido para organizar informações e características das doses e auxiliar na consulta e na escolha para processos de fertilização.

Projeto desenvolvido com alunos de Engenharia de Software em parceria com estudantes de Medicina Veterinária, com mentoria técnica da universidade e foco em uma solução acessível e de baixo custo.

Python Django HTML CSS JavaScript

Colaboradores Dev

Em fase inicial

CowProfit IA

Solução voltada ao acompanhamento da saúde e da produção de bovinos leiteiros. O projeto integrará sensores de condutividade elétrica e um chatbot via WhatsApp para registrar dados, acompanhar cada animal e gerar alertas sobre possíveis alterações associadas à mastite subclínica.

Comunicação dos dados via Bluetooth, registro da produção diária via mensagem de voz ou escrita com análise histórica para apoiar a identificação de padrões e alertas preditivos contra a mastite subclínica.

Desenvolvido em equipe multidisciplinar com estudantes de Engenharia de Software e Medicina Veterinária, dentro de um projeto universitário com mentoria técnica e foco em uma solução de baixo custo.

Python IA IoT Bluetooth APIs Análise de Dados
